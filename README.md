# TCP-Port-Scanner
Python TCP port scanner built with the socket library to identify open ports on authorized hosts. Created to practice networking, socket programming, and cybersecurity fundamentals.
Python Network Port Scanner

This project was built to practice Python programming, networking fundamentals, and basic cybersecurity concepts.
